# Car Trends

Static HTML dashboards for tracked car listing prices (Ferrari 488/F8, McLaren LT, Ford GT Gen 1).

## GitHub Pages

1. Repo Settings → Pages
2. Source: Deploy from branch `main` / root (`/`)
3. Site URL will be: `https://dboundz.github.io/car-trends/`

Dashboards are self-contained (data embedded). Chart.js loads from CDN.
